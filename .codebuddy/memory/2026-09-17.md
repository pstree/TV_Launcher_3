# 2026-09-17

## 首页右上角「设置」改为悬浮面板（不再遮盖全屏）

用户要求：点击顶部栏右侧设置按钮后弹出的面板改为悬浮窗，不要遮盖全部屏幕。

### 改动
- `components/dialog/SettingsDialog.kt`：
  - 删除整屏 `Color.Black.copy(alpha = 0.7f)` 遮罩；Dialog 内容根节点保留 `Box(fillMaxSize)` 但**全透明**，改为承载"点击空白处关闭"的背板（`detectTapGestures { onDismissRequest() }`）。
  - 面板本体 = `Column`（`RoundedCornerShape(16.dp)` + `OnWallpaperContainer`，与主屏图标网格容器一致）贴在 `Alignment.TopEnd`，上边距 `PADDING_DIALOG_EDGE + topBarHeight.dp`、右/下各 `PADDING_DIALOG_EDGE` → 卡片挂在顶部栏下方，时钟与 tab 行仍然可见。
  - 网格 `LazyVerticalGrid` 由 `fillMaxHeight()` 改为随内容自适应（LazyList/LazyGrid 主轴默认 wrap content，高度 = `constraints.constrainHeight(内容高度)`），面板高度 ≈ 420dp（5 行 × 60dp + 间距 + 20dp padding）。
  - 面板 `Column` 上加 `pointerInput { detectTapGestures(onTap = {}) }`，吃掉落在面板自身/按钮间隙的点击，避免误触背板关闭。
  - `DialogProperties.dismissOnClickOutside = false`：Compose 平台的"点外部关闭"是按**内容子 View 矩形**（`DialogLayout.isInsideContent`）判定的，内容铺满全屏时永远判定为"内部"而失效，所以必须自建背板。
  - 移除了面板内的 时间/日期 头部（`TimeText` + `DateAndWeekdayText`）：原来有它是因为黑遮罩把顶部栏时钟挡住了；现在面板挂在顶部栏下方、时钟仍可见，头部就是重复信息，去掉后卡片也更紧凑。
- `ui/launcher/activity/MainActivity.kt`：`SettingsDialog` 不再需要 `timeViewModel`，相应删掉 `TimeViewModel` 字段与 import。
  - 副作用：`components/text/TimeText.kt` 与 `ui/launcher/viewmodel/TimeViewModel.kt` 目前**无调用者**（保留未删，属可复用组件；若之后要恢复时钟或做桌面时钟可直接用）。

## 文件 tab 的文件列表换成深色半透明面板

用户要求：点首页 tab「文件」后，下面的文件列表加半透明背景。

- 原因：列表本来就有 `OnWallpaperContainer`（LightGray 30%），但壁纸换成必应每日壁纸这类浅色图后 30% 浅灰几乎不可见，看着像没有背景。
- `ui/theme/Color.kt`：新增 `OnWallpaperContainerDark = Color.Black.copy(alpha = 0.4f)`（注释说明是 `OnWallpaperContainer` 的深色变体，用于浅色壁纸下仍要看清边界的**内容面板**；`OnWallpaperContainer` 本身保留给主屏图标网格/顶部栏）。
- `ui/launcher/screen/FilesScreen.kt`：`LazyVerticalGrid` 的 `background(color = ...)` 改用 `OnWallpaperContainerDark`（圆角 16dp、宽度 0.5f、撑满剩余高度都不变）。
- 对比度自检：浅色壁纸下 面板比按钮浅、深色壁纸下 面板比按钮深，两种情况按钮都能区分出来。
- 设置悬浮面板（`SettingsDialog`）：用户随后确认"对，换成深色面板"，已一并换成 `OnWallpaperContainerDark`。
- 仍用浅色 `OnWallpaperContainer` 的地方（**未改**）：`MainActivity` 顶部栏 TabRow/时钟、`IconButtonTv`（顶部栏设置按钮）、`HomeScreen` 主屏固定图标网格、`AppsScreen` 应用列表。
- 验证：`sh gradlew :app:assembleDebug :app:lintDebug` → BUILD SUCCESSFUL。
